In pi, these tools are named `mcp__gh_tooling__<tool>` (read) and `mcp__gh_tooling_write__<tool>` (write), for example `mcp__gh_tooling__pr_view`. While they are deferred, which is the default, call a tool that is already loaded directly; otherwise query `tool_search` with the exact tool name and `limit: 1`, and if it loads a different tool, search again. A tool that `tool_search` loads is callable from your next call.
